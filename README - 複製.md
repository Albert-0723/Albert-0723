## 🚀 核心技術與專案實績

## 工業自動化與系統整合

- 自動化取放系統 (Auto Pick-and-Place)： 開發整合 CCD 視覺辨識與機器手臂之控制程式，實現待測物的自動化搬運與精準定位。
- 智能判斷演算法： 透過邏輯運算即時判定測試結果 (Pass/NG)，並驅動機器手臂執行自動分類與出料。
- 產線測試系統 (Powtron-ATS)： 持續優化自動測試程式架構，有效提升量產階段的系統穩定性與測試效率。

## 軟體開發與系統工具

- 系統工具開發： 涵蓋 Inverter 模擬通訊、EEPROM 讀寫工具、程式加密保護系統及自動化測試腳本產生器。
- 數據整合應用： 開發打卡 API 串接工具與測試資料自動匯入/匯出系統 (Datalog-Importer/Exporter)。
- 知識管理建構： 運用 Obsidian 建立個人 AI 知識庫，專注於 RAG (檢索增強生成) 與 LLM (大語言模型) 的技術落地。
